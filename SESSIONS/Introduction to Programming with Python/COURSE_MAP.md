# Introduction to Programming with Python: weekly materials

Use the numbered folders to follow the learning sequence. Keep each saved HTML assignment beside its matching `_files` folder so downloaded images and scripts continue to work. Source material in a folder does not mean the week has already been taught.

## Week 1 — Python foundations

Five lessons introduce programs, `print()`, variables and text; `input()`, f-strings and `strip()`; converting typed digits into numbers and basic arithmetic; defining and calling functions; and returning values. See [Week1/WEEK_NOTES.md](Week1/WEEK_NOTES.md).

## Week 2 — Making decisions with conditions

Week 2 introduces comparisons, `if`, `elif`, `else`, and combining conditions with `and`, `or`, and `not`. Learners use string tools to clean text, recognize greetings and classify file names, then convert a clock time to a decimal number. See [Week2/WEEK_NOTES.md](Week2/WEEK_NOTES.md) for the sequence and assignment map.

## Week 3 — Repeating actions and grouping data

Week 3 introduces `while` and `for` loops, lists and their methods, string methods and slices, dictionaries, tuples, and comprehensions. See [Week3/WEEK_NOTES.md](Week3/WEEK_NOTES.md) for lesson order and practice mapping.

## Week 4 — Finding, handling, and preventing errors

Week 4 teaches syntax, runtime, and logic errors; `try` and `except`; repeating prompts; validating boundaries; and debugging step by step. See [Week4/WEEK_NOTES.md](Week4/WEEK_NOTES.md) for the five-session sequence and practice map.

## Week 5 — Using Python libraries

Week 5 introduces built-in and external libraries, random choices, command-line arguments, and the basic idea of requesting data from an API. See [Week5/WEEK_NOTES.md](Week5/WEEK_NOTES.md). API keys must stay out of browser code and shared examples.

## Week 6 — Testing code with pytest

Week 6 introduces unit tests, `assert`, normal and boundary cases, pytest naming and discovery, and the main guard used to keep imports from starting prompts. See [Week6/WEEK_NOTES.md](Week6/WEEK_NOTES.md). Running a full pytest project requires a local Python environment.

## Week 7 — Working with files and structured data

Week 7 moves from typed input to saved text, CSV tables, and basic image editing with Pillow. See [Week7/WEEK_NOTES.md](Week7/WEEK_NOTES.md) for the sequence and assignment map. File paths, supplied files, and Pillow require a suitable local environment.

## Week 8 — Finding patterns in text

Week 8 introduces regular expressions from simple patterns to capture groups and input validation. See [Week8/WEEK_NOTES.md](Week8/WEEK_NOTES.md). Lessons distinguish matching a format from verifying real-world data.

## Week 9 — Organizing programs with objects

Week 9 introduces classes, objects, instance variables, methods, validation, and class-level data. See [Week9/WEEK_NOTES.md](Week9/WEEK_NOTES.md). Classes are presented as a tool for related data and actions, not a requirement for every program.

## Week 10 — Recursion and a final project

Week 10 covers beginner-friendly code clarity topics from “Et Cetera”, recursion, and a small capstone that revisits functions, validation, testing, and debugging. The supplied final-project requirements include a main program, at least three additional functions with tests, project documentation, and a short demonstration. See [Week10/WEEK_NOTES.md](Week10/WEEK_NOTES.md) for milestones and scope guidance.
